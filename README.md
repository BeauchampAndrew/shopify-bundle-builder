# Build-Your-Own Bundle for Shopify

A build-your-own-box section: pick a box size (4, 6 or 8) with a discount per size, fill it with +/- buttons, see every slot, a live total and "you're saving $X", then add the whole box to the cart in one click. No app.

Built with Claude Code on camera for the BS&Co YouTube channel. Install steps, settings and customization prompts go here once the build is done.
